# TakeMeter label definitions
# Each label is followed by its one-sentence definition.
# These definitions must match the README Label Taxonomy section.

low_context: A post that states a question or problem but gives little meaningful explanation or supporting background.
some_context: A post that provides relevant background, a specific topic, or a previous difficulty but does not sufficiently develop the central situation.
detailed_context: A post that includes multiple concrete, relevant details that work together to explain the author's problem, experience, or argument.
